# Dataset

This project uses the N-BaIoT / BoTNeTIoT-L01-v2 dataset.

**Download it here:**
https://www.kaggle.com/datasets/azalhowaide/iot-dataset-for-intrusion-detection-systems-ids

After downloading, place the CSV file in this folder as:
`data/BoTNeTIoT-L01-v2.csv`

This file is intentionally excluded from the repository (Git) due to its size (~1.6GB).
