SentryStream - HBase Schema
===========================

Table Name:
sentrystream_predictions

Column Families:
1. cf
2. features

cf:attack

cf:prediction

Row Key Design:
---------------
<device_name>#<event_timestamp>#<unique_id>

Example:
device_01#2026-08-19T00:45:21#000001


Data Types:
-----------
device_name       -> STRING
attack            -> STRING
attack_subtype    -> STRING
original_label    -> INT
event_time        -> TIMESTAMP
prediction        -> INT
features          -> DOUBLE


Label Convention:
-----------------
0 = Attack
1 = Normal


Prediction Convention:
----------------------
0 = Attack
1 = Normal


Purpose:
--------
HBase is used as the fast NoSQL storage layer for real-time
IoT prediction results.

Hive/HDFS:
- Historical dataset
- Batch analytics
- Large-scale storage

HBase:
- Fast lookup
- Real-time prediction access
- Device-based queries
- Recent event retrieval
